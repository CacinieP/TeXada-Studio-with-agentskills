# OCR 校订与原稿对照

用于 OCR 转换的 Markdown / TeX 清洗、校订或前后对比。一般格式清洗仍保持文字和公式原样；
用户已经要求对照原稿校订时，可以直接完成证据明确的内容修复，无需逐处确认。

## 先确定材料与范围

- 区分原 PDF / 页面图像、OCR 原始结果、已有清洗结果。记录实际输入的哈希与来源。
  旧报告中的路径可能已迁移，按文件内容或哈希确认，不能把旧的 after 当成新基线。
- 同时记录 PDF 物理页（从 1 开始）和书中印刷页。分段文件名只给范围，不证明段落对应哪页。
  用标题、定理号、图号和句子锚点定位。对照原页图像；文本提取仅作辅助。
- 大批材料先明确机械处理范围和人工/agent 原页核对范围。存在页边界不明或缺页时，
  记录未解决项并继续独立可验证部分；不自动推断缺失正文。
- 默认在副本上做 OCR 实验。保留资源相对路径；若移动 Markdown，复制所需资源或明确
  重映射并记录，不能交付大量断链。禁止为试验把整本材料上传到外部模型或公开仓库。
  用户明确授权某种上传时按该授权范围执行。

## 逐项判断

| 情况 | 行为 |
|---|---|
| 仅无歧义的源码空白 | 保守脚本处理，验证幂等与保护区域 |
| 原页清楚显示漏掉/错位的字母、负号、上下标或表格值 | 局部恢复并记录页码、上下文和替换内容 |
| 旁注、图注、展示字符串被错识为正文或标题 | 按原页结构恢复，检查阅读顺序和引用 |
| 单凭 OCR 文本存在多个合理解释 | 保留原文，列为待核对；可给候选，不代替原文 |
| 内容在原页就如此，或属于作者的写法 | 保留，不以“数学上更合理”为由替换 |

特别检查作用域：分子/分母、根号范围、上下标、量词、等号与不等号。表格按单元格位置
核对，不用“全表数字集合相同”代替位置检查。不要全局统一 R / M / l / 1 等易混字符。
OCR 遗漏的公式定界符也需要恢复；仅检测现有 `$...$` 会漏掉这些错误。

## 修改与对比

每项内容修改至少有：唯一 ID、原片段、新片段、源 PDF/图像位置、修改依据。
片段应包含足够上下文以唯一定位。证据不足的项独立记录 `review`，无需伪造补丁。
`scripts/apply_verified_edits.py` 可检查源哈希、唯一匹配、重叠及备份，再执行人工/agent
已核对的补丁；JSON 中写入证据字段并不证明校订正确。

将机械格式层与原页校订层分开保留，便于回答哪种机制产生了改动。对比旧版本时使用同一
原始输入，并单独列出旧版已完成、新增修复、仍未解决的问题。若核对原页后发现旧报告不准，
更新本轮结论并保留依据。

正文、公式和数字可以在获授权且有证据的 OCR 校订中改变，因此不能再强制“全部公式原样”
作为唯一验收标准。改为逐项核对批准的变化，并验证批准范围之外的字节没有变化。

## 版式复刻与渲染对比

- OCR 转录只承载文字内容，不承载版式；版式复刻、还原或"照原图修版式"的任务必须直接
  查看原页图像。宿主不能看图时使用用户授权的视觉模型工具，并遵守上文的上传授权约束。
- 不要凭 OCR 文本、注释或想象补充原稿中不存在的样式元素；描述里没有的结构（如边栏、
  横幅、页脚部件）先确认存在再实现。
- 对比流程：把结果渲染成页图像（如 `pdftoppm`），与原页成对送审，要求按「项目｜原版｜
  复刻」列出差异（边栏、标题体系、字体族、页脚），按差异逐项修改后再次渲染复核。
- 视觉模型批量看多图时会张冠李戴（认错页码、页序甚至页面类型）；关键页面逐张单独确认，
  同一模型两次描述冲突时以单独确认为准，并在交付时注明哪些结论来自视觉核对。
- 宿主模型不能直接读图时：用**同一份结构化清单**对每张原版页与复刻页各做一次单图送审
  （清单项覆盖本任务的关键版式元素：边缘竖条/横幅、章号块、标题体系、面板标题位置、
  页脚部件、栏数、题号样式），由 agent 对两份清单逐项 diff，而不是让视觉模型同图对比或
  自由描述。这样同时绕开宿主读图限制、避免张冠李戴，且 diff 结果可复核、可重放。
- 颜色取证：可让视觉模型报告关键强调色的近似 hex，但只用于确定色系家族，不当作精确
  取值；交付时注明颜色结论来自模型估计。优先用已有的、被多数页描述一致的色系。
- 版式复刻模板常按逻辑重排内容流：页码沿用模板自身体系，并在注释或 README 写明页码
  语义（目录页码指向原书还是模板）；除用户明确要求逐页影印式复刻外，不为对齐原书页码
  重排页序。
- 版式修改会改变分页（如新增双栏、横幅增高把内容挤到下页）：分页漂移后必须用内容锚点
  重新配对原版页与复刻页再复核，不能沿用旧页码配对。
- fancyhdr 页脚与 eso-pic 背景钩子共用布尔开关时：页脚宏在页面构建阶段展开，BG 钩子在
  shipout 阶段执行并在钩内 `\global` 复位，对下一页生效；两种条件部件（页脚形态、竖条
  有无）要逐页分别验收，它们可能各自独立出错。
- 跨页背景元素（页左竖条等）需按页条件化时，用 shipout 钩子加布尔开关
  （eso-pic 的 `\AddToShipoutPictureBG` 配 `\newif`，置位后在钩子里 `\global` 复位）；
  验收时逐页确认元素应出现/缺席的页面是否正确。
- 源码注释写「第 N 页」不等于分页正确：缺 `\clearpage` 时章首页会与后续内容挤在同页。
  验收用 PDF 文本提取逐页摘要（首页行、页脚行）核对实际页序，不以注释或渲染页数为准。
- 分页规范：硬分页（`\clearpage`）只用于必须独占的页面（章首页、插页、练习册页）；
  节与节之间用 `\needspace{N\baselineskip}` 防标题孤行即可。小节间滥用 `\clearpage` 会
  产生大片空白页，页数变多但版心密度反而更差。验收看各页文本行数分布，不只看总页数。
- 页脚奇偶件（页码与页眉/页脚文字的先后顺序）容易只在奇数页核对而漏掉偶数页写反；
  奇偶页各取一页，对照原版确认「页码｜书名」的相对顺序。
- 读图不稳定或需可复核证据时，对渲染页做**像素签名校验**：竖条宽度（扫描近似色连续列）、
  强调色是否出现在章号/页脚预期区域、竖排字母的着色行数。签名结果写入验收记录，
  与人工看图结论并列；二者冲突时以单独重新截取的原图为准。
- 原图是整页截图而非独立插图文件时，先裁出插图区再使用；用非白像素量与区域均值色
  粗验裁剪是否命中（空白裁片或整页误裁都要重裁），不要把整页扫描直接 `\includegraphics`。
- 最容易漏掉的识别特征按优先级核对：分页归属、边缘竖条形态（宽条竖排字母堆叠 ≠ 细条
  旋转整词）、目录/部件在页顶还是页底、章号是否带装饰线、标题字母的混色与间隔点样式。

## 验收边界

- 公式语法测试记录渲染器版本、参数、提取方法、通过/失败数和未覆盖边界。
- 单独送入 KaTeX 的公式可解析，不代表 Markdown 会识别它；例如紧接字母的 `$i$th`
  在部分方言中仍显示源码。按原稿与目标预览局部修正边界，不全局改写定界符。
- Markdown 保持原方言；没有 TeX 主文件时不把片段包装编译后宣称原项目编译通过。
- 对实际改动对应的原页和新预览做视觉核对；表格数字与数学语义还需逐项比对。
- 扫描了全库不等于校订了全库。已知样例是回归证据；独立选取的新页才提供额外泛化信息。
