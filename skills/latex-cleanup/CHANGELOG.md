# 版本记录

## 0.2.3 — 2026-09-26

- 版式复刻验收新增：注释页码≠实际分页（用 PDF 文本提取核对页序）、奇偶页脚顺序逐页核对、读图不稳时的像素签名校验、整页截图裁插图的方法、最容易漏掉的识别特征优先级清单。
- 分页规范：硬分页仅用于独占页，小节间用 needspace；按页文本行数分布验收。
- TeX 实现：tikz 水平细线用投影写法防倾斜（`a -| b`）；Tectonic 挂起先查联网索引。
- 以上均源自《Triangle》版式复刻实战。

## 0.2.2 — 2026-09-25

- 版式复刻与渲染对比新增：宿主不可读图时的结构化清单单图送审与两份清单 agent diff 流程；视觉模型取色只用于确定色系家族；复刻模板页码语义（模板页码 vs 原书页码）需写明；版式修改导致分页漂移后须用内容锚点重新配对复核；fancyhdr 页脚与 eso-pic 钩子共用布尔开关的展开时机与逐页验收。

## 0.2.1 — 2026-09-25

- 增加字体与宏包陷阱：fontspec 系统字体缺失、tcolorbox 虚线框写法、西文文档 CJK 缺字的 xeCJK 处理与无害警告识别。
- 增加版式复刻与渲染对比规则：以原页图像为准、pdftoppm 渲染成对对比、视觉模型批量识图需逐张确认、不发明原稿没有的元素。
- 增加引擎 magic comment 与编辑器配方冲突（spawn ENOENT）、Fira Math 获取途径与跨页背景元素条件化模式。

## 0.2.0 — 2026-09-22

- 增加固定输入哈希的批量 OCR 副本清洗、已核实片段合并与逐本结果记录。
- 增加可重放的普通 diff / 转义 JSON 文本补丁，完整 OCR 留在本地。

## 0.1.0 — 2026-09-22

- 增加按原 PDF / 图像校订 OCR 的流程：页码定位、内容与结构修复、歧义保留、清洗前后对比。
- 增加精确补丁工具：源哈希、唯一匹配、非重叠验证、逐字节备份与修改依据，默认预览。

## 0.0.1 — 2026-09-09

首个版本化发布：将原有纯指令 LaTeX 清洗技能扩展为 TeX / Markdown 清洗流程，继续使用
用户现有的 VS Code 编辑与预览配置。

- 区分检查、清洗和修复；保留正文、数学含义、代码、引用用途与未决 TODO / FIXME。
- 修正数学符号、引用命令、图片扩展名及 BibTeX 字段的过宽规则，按上下文和条目类型处理。
- 增加保守空白脚本，默认仅检查，写入前逐字节备份，保留换行、BOM 和文件权限。
- 修复公式中 `\begin{array}` 导致整份 Markdown 被跳过的问题；区分行内/展示公式、代码示例
  与原始 TeX，保护公式源码的同时继续检查普通正文。
- 增加编译记录脚本，保留真实退出码，检查最终日志，并区分成功、失败、超时与未执行。
- 增加格式、文件保护、编译进程和多文件引用的回归样例。运行方式见 [回归样例](tests/CASES.md)。

### 已知限制

- 数学/代码范围之外的原始 TeX 环境、未支持的扩展容器仍会跳过整份 Markdown；公式与行内代码
  混排等边界不明确的情况继续保守保留，有依据的局部修改仍可由 agent 完成。
- 不自动纠正 OCR 正文、公式、表格数据或旁注位置；公式能渲染不代表识别内容正确。
- Markdown 脚本需要可选依赖 `markdown-it-py`；编译需要现有 Tectonic 或 latexmk 与相应引擎，
  不自动安装依赖。构造样例通过不代表真实长论文、中文字体或全部投稿模板已经验收。
