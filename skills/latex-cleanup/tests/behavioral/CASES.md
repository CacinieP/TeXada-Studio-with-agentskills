# Agent 行为测试

这些自构造任务用于前向执行检查，不是单元测试，也不自动调用付费模型。

```sh
python3 tests/behavioral/run_suite.py prepare --outdir /path/to/new-run
# 给独立 agent 提供技能路径、各案例工作目录及其中的 request.txt。
# 不提供本文件、检查器、预期答案或先前报告；仅允许在案例目录中操作。
python3 tests/behavioral/run_suite.py check --outdir /path/to/new-run
```

| 任务 | 文件层验收 | 人工复核报告与轨迹 |
|---|---|---|
| check-only | 源码完全不变 | 是否定位环境不匹配，是否如实描述实际检查 |
| cleanup | 只移除普通段落的单个尾空格 | 公式、代码、CRLF、硬换行、引用依赖是否受保护 |
| repair | 修复环境配对及原稿缺失的 mathbb 宏包，真实构建结果和 PDF 存在 | 是否执行编译并读取日志，是否夸大视觉验收 |
| uncertain-ocr | 原文和缺图占位保留 | 是否列出无法据源确认的内容，不猜补 R/M/l/1 |

检查器只验证可观察文件与构建记录，不凭 report.md 的措辞判断正确性。必须人工查看报告
和工具轨迹后另记结论；不能把伪造 build-result.json 当成真实执行证据。Tectonic 或其缓存
不可用时记录环境限制，修复案例尚未通过编译项。不要更改预期断言来制造通过。

源材料 OCR 案例另外开展：给独立 agent 尚未提供答案的一页原 PDF / 图像与 OCR 分段，
要求只校订该页并保留其他内容。复核页码、实际差异、未解决项及公式解析。真实书籍与页面
截图不加入本仓库；经用户授权只保留文本 diff、来源页码/哈希与验证摘要。

一次运行只说明该 agent 在这些任务上的观察结果，不代表自然语言触发率、跨模型可靠率或
整个语料的准确率。用于改进技能的案例成为已知回归集，下一次独立验证应增加新任务。
