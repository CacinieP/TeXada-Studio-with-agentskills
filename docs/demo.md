## 自己复现

不需要模型时，先运行 [README](../README.md) 的 CLI fixture。需要复现界面时，按 Studio 依赖表准备本机模型、编译器和字体，使用合成样本 `report-01.tex`。逐项核对：问题定位 → 生成候选 → diff → 人工采用 → 导出报告。

传播时优先展示具体错误和修复依据，保留“语法通过不等于语义正确”的说明。素材用途和发布文案见 [发布与传播计划](launch-plan.md)。
