## 改为公开之前必须完成

- [ ] 处理历史提交中的 `samples/docs/GTM249-p101-120.tex`。删除当前文件并不会删除历史；须取得明确再分发授权，或经仓库所有者批准后在私密备份基础上清理历史 / 创建干净发布仓库。

- [ ] 审阅 AGPL 的授权范围，以及来源快照和品牌资源的权属。
- [ ] 确认实际部署版本的对应源码可公开访问；如有本地修改，提供该版本源码，并更新界面源码链接。

源码包由 `bash scripts/package.sh` 从当前提交生成，不包含历史；Git bundle 与完整 clone 包含历史，不得当作已清理的公开源码包。

## 验证记录约定

发布说明需写明提交号、测试环境、实际运行的测试，以及未执行的浏览器、真实模型、TeX 编译和断网检查。密钥扫描没有命中不等于完成版权审查。不得把准备清单当作赛事官方认证。
