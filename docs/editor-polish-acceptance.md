# TeXada Studio 编辑器升级验收

日期：2026-11-02。范围：当前 Apple Silicon Mac 的本地版本，分支 `feat/texada-studio-complete`。本轮延续已交付的本地模型与文档工作流，完善品牌、编辑操作和长文档交互。

## 已完成

- 沿用 TeXada Agent 的 `{∫Σ}` 品牌：32px 标签页图标、128px 顶栏图标及高清源图；统一工具栏、导航与分隔条 SVG 图标，保留按钮文字或可访问名称。
- 保留 TeXWizard 的浅色外壳，编辑区采用 Agent 深蓝色系。文件搜索、大纲置于侧栏，图片识别和高级工作流默认折叠。
- `⌘/Ctrl+Shift+P` 打开可搜索命令面板，支持上下键、回车、Esc 与焦点恢复；执行真实文件、编辑、编译和审阅操作。
- Monaco 原生查找与替换；LaTeX 命令、注释、数学及原样区域高亮，25 个本地片段补全，包含成对环境和可切换占位符。
- 章节大纲识别常用节标题、星号、短标题与嵌套花括号；跳过注释和常见逐字区域，点击跳转到对应行。`⌘/Ctrl+Shift+O` 可打开章节导航。
- 字号、自动换行、小地图在本机浏览器持久化；实时行列、选区和字符统计；保存中、未保存和已保存状态明确显示。
- 编辑与候选标签支持方向键、Home、End。全局快捷键避开中文输入法组合事件。
- 按 Monaco 文档与版本缓存全文统计和大纲；光标移动仅更新位置、选区及当前章节。

## 使用入口

双击交付目录内的 `启动 TeXada Studio.command`。常用操作也可从顶栏“命令”中搜索；源码、模型和文档仍在本地处理。保存采用版本检查，修复仍需明确审阅，PDF 导出仍绑定当前内容。

大纲与高亮用于写作导航，不解释完整 TeX 宏，也不证明数学结论。当前工作单位仍为单个 `.tex`；本轮未扩大为多文件 TeX 工程管理器。原有本地模型/OCR验收及其范围见[本地版验收](local-studio-acceptance.md)。
