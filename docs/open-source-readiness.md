# TeXada 开源准备审查

检查日期：2026-09-28。范围：当前源码与可达历史、仓库入口、首次安装、社区协作、版本交付及传播材料。仓库仍保持 PRIVATE；本轮不发布文章、视频或 Release。

本文主体保留开源准备阶段的审查快照。后续案例与文档补充已新增27例检查器案例、3份 Studio 文档、Skills 技术报告及文档目录，并修复检查器和表格候选边界；最新分组结果与测试计数见 [验证记录](validation.md)，阅读入口见 [文档目录](index.md)。

## 结论

基础许可和工程文件已经具备；原先主要缺的是新用户上手路径、实现范围的一致表述，以及从演示到试用、反馈和贡献的入口。这轮完成了对应改进。**现在适合邀请有仓库权限的用户试跑；公开上线仍需维护者确定时间、配置漏洞接收入口并验证所有公开链接。**

这是逐项检查，不给没有统一口径的“开源成熟度百分比”。文档齐全、一次测试通过和实际社区采用是三件不同的事。

## 本轮验证

- 从已提交源代码导出独立目录，新建 Python 3.13 虚拟环境，仅安装 `harness/requirements.txt` 后执行 README fixture 命令；首轮为 exam OK=3、paper OK=2/NEEDS_HUMAN=1、report OK=2，第二次 8 个终态节点跳过。
- 新建开发依赖环境，Web Python 测试 21 项通过；Studio JavaScript 页面逻辑检查通过；latex-cleanup JavaScript 检查 37 项通过。
- latex-cleanup Python 测试首轮发现 1 个时序敏感用例：它假定子进程在 1 秒内输出。拆成真实超时与确定性输出保存两项后，全套 77 项通过。未修改编译器运行时代码。
- `CITATION.cff` 通过 cffconvert 的 CFF 1.2.0 schema 验证；本轮 Markdown 本地链接、shell 示例语法与 Git 差异格式检查通过。
- 传播短片完整解码通过，时长 41.6 秒、约 2.30 MB；是三段原速节选。分享封面为 1280 × 640 PNG、约 172 KB，已检查实际渲染。
- 已扫描可达文本文件版本，未发现当前已知演示 token。扫描没有命中不能证明所有历史、第三方权利和其他秘密都已审阅。
- Gitleaks 初扫 41 个提交有 12 个候选：10 个为语音服务任务标识，2 个为摘要匹配的 Monaco 上游代码表达式。逐项复核并记录精确例外；公开准备版语音清单去掉任务标识。没有使用整目录排除来掩盖新命中，详见 [扫描复核](security-scan-notes.md)。

本轮是文档、素材和一项测试稳定性完善，没有重新运行真实模型推理、全链路断网或跨平台部署。已有实机证据见 [验证记录](validation.md)，不扩大其结论。

## 公开前的优先次序

1. **P0：定版本、审来源。** 选定具体提交，复核拟公开 refs、附件、版权来源与部署源码对应关系；不要混入旧私密备份。当前未创建发布 tag。
2. **P0：开放可访问入口。** 按维护者决定改变可见性；配置并测试私密漏洞报告；用未登录浏览器检查仓库、源码附件与全部媒体链接。私有 URL 不等于已经开源发布。
3. **P0：交付首个预发布包。** 从同一提交生成源码与校验值，使用候选 Release 文案，明确不可信 TeX、多用户与 OCR 的限制。
4. **P1：邀请少量真实用户复现。** 先收集安装失败与误改/漏检样本，处理后再扩大传播；3 人试跑只是内部目标，不是现有成绩。
5. **P1：做一轮内容传播。** 用短片引入一个真实可复现问题，用技术文章说明实现，再把读者引导到 fixture 和 Issue。所有渠道回到同一仓库入口。

独立官网、大量徽章、多平台账号、付费流量、独立聊天群都不是当前最紧迫的工作。README、素材、可试跑路径和及时处理反馈更值得先完成。
