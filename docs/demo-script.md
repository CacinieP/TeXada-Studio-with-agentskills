# 五分钟内演示脚本

实际提交表要求视频5分钟以内，未要求无剪辑。本版目标约2分40秒，共8个场景；精确时长以最终文件检测为准。画面使用真实浏览器操作，说明部分对应实际源码与已有实验记录；旁白为合成语音。不录制地址栏、节点账号、凭据或分配端口。

## 八个场景

| 场景 | 画面和叙事 | 保留的事实边界 |
| --- | --- | --- |
| 1. 为什么需要它 | 展示45、60与错误合计115，说明能编译并不代表正确 | 合成样本，不冒充用户真实错误分布 |
| 2. 定位可见问题 | 源码、PDF预览、分析与合计定位；候选为105 | 规则计算，不需要模型；明细数据仍要核对 |
| 3. 审阅与采用 | Monaco diff、明确采用、导出文档及质检报告 | 生成候选不等于已经采用，不自动保存编辑器内容 |
| 4. 公式与人工判断 | 缺少下标的公式经真实模型提出候选并回判 | 语法通过不证明作者原意；无页面图像输入 |
| 5. Skill 实际进入请求 | 展示读取正文、系统消息、摘要和开关对应关系 | 固定程序编排；on/off仅比较指令干预，不称自主规划 |
| 6. 失败与恢复证据 | 被拒候选、检查原因、上下文摘要与持久任务记录 | 中断任务需新建，不自动重放模型调用 |
| 7. 已完成的先导实验 | 12条输入、三组36条结果、17次请求尝试及一次超时 | 两模型组各5个语法接受候选，最终文本无组间差异；人工复核未完成，无效果提升结论 |
| 8. 范围与复现 | 可信文档、简单表格、样本及技术资料入口 | 无自动OCR、复杂表格或多用户服务；仓库仍私有 |

## 剪辑与验收

模型等候片段可以剪去，但必须在画面标记“已剪去等待”；结果和任务记录仍对应真实请求，不把缩短后的播放时间写成模型速度。发生失败时保留失败证据，不用替身结果冒充成功。若重新录制，应记录新任务，而不是拼接两个任务伪造一次连续运行。

本次源码版本为 `e0cc8f8`（历史脱敏后的对应提交），最终源码包为 由交付包文件名及SHA256清单标识；相对录屏版本仅更新文档、截图和扫描例外。精确时长 160.7秒（2分40.7秒）。浏览器、编译和导出验收：源码、预览、问题定位、diff、报表采用、tex与报告导出完成；公式报告已导出，因编译失败未导出PDF。画面脱敏与完整解码验收：1080p横屏；节点名称与资源信息遮罩；无地址栏、凭据或分配端口；逐场景画面检查与完整解码通过。
