# 连续演示脚本

按 [README](../README.md) 启动 Studio，确认模型、Tectonic 和 Poppler 可用。下面对应当前222.071秒实录；复跑时按界面完成状态推进，完整保留等待。

| 环节 | 实际操作 | 查看什么 |
| --- | --- | --- |
| 正常讲义 | 打开 `math-clean.tex`，键入注释再撤销；调整字号，滚动源码和预览 | 分式、积分、极限与递推；撤销恢复原文 |
| 定位问题 | 打开 `math-delimiters.tex`，点击分析，再点击L20问题 | 缺失右侧定界符；原稿编译失败 |
| 生成候选 | 点击“Skill 一键修复”，展开日志并等待完成 | 真实请求和检查记录；本次任务耗时70.86秒 |
| 审阅采用 | 查看左右 diff，核对分子、分母与条件，再点击采用 | 本次仅补 `\right)`；修复后编译通过 |
| 预览导出 | 切换100%与适应，导出PDF、TeX和质检报告 | 三份下载完成；先导出，再切换文件 |
| 语义反例 | 折叠上一任务日志，打开 `math-semantics.tex`，定位L18 | 积分值错误，但语法检查0问题且能编译 |
| 样本边界 | 打开 `math-fractions.tex`、`math-integrals.tex`、`math-align-boundary.tex`，最后回正常讲义 | 分组错误可定位；多行环境未抽取，编译仍会报错 |

## 操作要点

- 点问题卡片可跳转到源码行；diff生成后可用A+调整字号。
- 预览100%显示原图大小，窄栏可能裁切页面；点击“适应”恢复整页，确认公式完整可见。
- 点击“Skill 活动日志”标题可折叠或展开。切换文档前折叠上一任务日志，避免混淆。
- 正常公式和语义反例保留原文。修复失败时展示实际结果与原因。

当前实录有7段统一合成女声与中文字幕，操作、结果和文件摘要见[动态录屏说明](dynamic-demo.md)。以前的8场景分段讲解版见[历史索引](demo.md#历史演示)。
