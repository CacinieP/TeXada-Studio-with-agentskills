# 五分钟内演示脚本

新版约2分56秒，共8个场景。前四场景使用真实浏览器操作，后四场景为明确标注的机制与范围说明；旁白为合成语音。视频不包含地址栏、节点账号或凭据。精确时长与文件摘要见[媒体清单](media/demo-manifest.json)。

| 场景 | 画面和叙事 | 事实边界 |
| --- | --- | --- |
| 1. 数学讲义 | `math-clean.tex` 的分式、积分、极限、递推关系与源码并排显示 | 原创合成样本，不代表自然错误分布 |
| 2. 定位与候选 | `math-delimiters.tex` 缺少 `\right)`；真实模型提出一处修复 | 1次请求；省略等待有画面提示，不伪造结果 |
| 3. 审阅与导出 | Monaco diff、人工采用、成功预览与 PDF/tex/报告导出 | 检查器接受与人工采用分开；修改符合这份讲义的明确意图 |
| 4. 积分语义反例 | 从0到1对x积分错写1；正确值1/2 | 能编译且语法0问题；不声称有数学真值验证 |
| 5. Skill 进入请求 | 正文加载、系统消息、摘要与开关 | 当前仅公式 Skill 接入宿主，工具和重试固定编排 |
| 6. 失败与恢复 | 候选/拒绝原因与上下文绑定记录 | CLI续跑与Studio读取完成结果不同；中断任务需新建 |
| 7. 新增样本库 | 新增8份、总13份；4类语法缺陷、正常/语义/抽取/引用边界 | 零问题不等于正确，零抽取单列；作者参考修订不代表模型效果 |
| 8. 适用范围 | 可信文档、公式与简单表格、资料与复现入口 | 无自动OCR、复杂表格、多用户服务；仓库仍私有 |
