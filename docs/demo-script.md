# 五分钟内演示脚本

实际提交表要求视频 5 分钟以内，未要求无剪辑。本轮使用浏览器真实操作，后期加入中文字幕和合成语音；不伪造接口结果。不要录制地址栏、终端凭据或分配端口。

## 演示顺序

1. 打开 Studio 的合成 `report-01.tex`，说明范围是行内公式语法与简单表格合计。
2. 展示两行利润 45 和 60、错误合计 115，以及问题定位行号。指出成功编译不代表数值正确。
3. 点击修复，展示 115 → 105 的候选对比。说明该步骤为规则重算，无需模型猜测。
4. 采用候选到编辑器，展示预览并导出质检报告。
5. 切换 `exam-01.tex`，展示不完整下标、括号和小数合计问题，点击真实本地模型修复。
6. 保留真实任务日志；说明当前模型输入是文本，不包含原始图像。
7. 展示候选 diff，特别说明 `a_` 补成 `a_1` 不能证明原意，需要人工确认。
8. 为合成演示采用候选，导出 tex、PDF 和报告，说明仍未实现的 OCR、多用户功能。

录制时模型已做过功能彩排，因此耗时不是冷启动基准。精确时长、样本与结果见本轮验证记录。若运行失败，保留失败证据并重录，不以剪辑或替身替换成功结果。
