# TeXada Studio E2E 可用性迭代与 v0.1.0 公证发行 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 E2E-1..5 五条真实场景把 TeXada Studio 迭代到端到端可用，并产出公证 DMG 的 v0.1.0 发行。

**Architecture:** 新增单一驱动脚本 `scripts/e2e_release_check.py`，以真实 uvicorn 后端 + 真实 Ollama 模型 + 真实 LaTeX 编译跑五条场景并写证据；拦路缺陷走小 PR 修复循环；版本切面后由 GitHub Actions `bundle-build` 产出公证 DMG。

**Tech Stack:** Python 3.13（`.venv`，stdlib `urllib`/`unittest`）、FastAPI/uvicorn、Ollama（`openbmb/minicpm-v4.7`、`minicpm-ocr`）、Tectonic/Poppler、py2app、notarytool。

**Spec:** `docs/superpowers/specs/2026-11-12-e2e-release-design.md`（本计划与其一起读）

## Global Constraints

- 发行版本一律 **v0.1.0**：tag、GitHub Release、`CFBundleShortVersionString` 均为 `0.1.0`（spec §5.4，用户定）。CHANGELOG 既有 `0.2.0-beta.x` 历史条目保留原样。
- E2E-1..5 全过才可发行；**发布运行禁止 `--skip-model`**（spec §5.2）。
- 证据一律写 `docs/evaluation-results/e2e-release-01/`（`e2e-results.json` + `SUMMARY.md`）。
- 合并任何 PR：CI 全绿 + 用户批准；**触发 CI（`gh workflow run` / 为触发 CI 而推 tag）：逐次用户批准**。
- 全量回归命令集（每个代码任务收尾必跑）：
  ```bash
  for d in harness/tests webui scripts desktop; do .venv/bin/python -m unittest discover -s $d -p 'test_*.py'; done
  for t in webui/test_studio.cjs webui/test_latex.cjs webui/test_templates.cjs skills/latex-cleanup/tests/test_audit_math.cjs; do node $t; done
  ```
- 后端启动命令（repo 根，端口取空闲端口）：`DEMO_TOKEN=<random> .venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port <port> --app-dir webui`；所有 API 请求带 `?token=<DEMO_TOKEN>`。
- 模型端点：`http://127.0.0.1:11434/v1`（Ollama）；OCR 模型 `minicpm-ocr:latest`，修复线默认 `minicpm-v4.7-35b-a3b-q4`（以 `/api/nodeinfo` 的 `repair_model`/`ocr_model` 为准，勿另硬编码）。
- macOS ARM；AGPL-3.0-only；分支名 `feat/fix/chore/docs` 前缀，禁止 `agent/` 前缀。

## Review Focus

1. **模型服务缺失/中途掉线**：必须响亮失败，不许静默跳过——Task 2 预检测试（端点不可达 → `PreflightError`）与 Task 4 运行中失败测试（`passed=False`）钉住。
2. **模型把文档改坏 / NEEDS_HUMAN 冒充通过**：E2E-2 断言原文备份、checker 复核字段与内容哈希变化同时成立——Task 4 测试钉住。
3. **E2E-4 假绿**（只写不读、或同进程读回）：必须杀掉后端、新进程读回——Task 6 测试钉住（fake call 序列含第二次 boot）。
4. **#50 SIGTERM 回归**：.app 收 SIGTERM 必须限期退出且 code=0——Task 7 沿用 `desktop/test_desktop.py` `NativeTerminateIntegrationTests` 的断言模式。
5. **发错包**（本地构建冒充 CI 公证产物）：发行校验必须针对下载的 CI 产物做 spctl + checksum + 版本号三重核对——Task 11 步骤钉住。

def test_write_evidence_emits_json_and_summary(self):
