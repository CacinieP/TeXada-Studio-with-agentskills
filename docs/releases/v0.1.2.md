# TeXada Studio v0.1.2

双平台稳定性与端到端可用性维护发行版，同时提供 **macOS 15+ / Apple Silicon 自包含公证安装包**（`CFBundleShortVersionString` `0.1.2`，build `7`）、**Windows 10/11 x64 自包含便携桌面包**（`TeXada-Studio-Windows-x64.zip`，可执行版本 `0.1.2.0`）与固定提交跨平台源码包。

## 修复与改进

- **桌面端原生文件导出、偏好持久化、未保存关闭提醒与 macOS 菜单撤销/重做（#54 / #81 / PR #85）**：
  - 修复 macOS `WKWebView` 与 Windows `WebView2` 中点击导出 `.tex` / `.pdf` / 质检报告无响应的问题：开启 `ALLOW_DOWNLOADS` 并提供最小桥接 `save_file`，直接弹出系统原生保存对话框并以原子写入落盘（支持覆盖既有文件）；浏览器模式延长 Blob Object URL 回收窗口，消除下载竞争。
  - 启用持久化 WebView 本地存储（`state_dir/webview-storage`，权限 `0o700` 并拒绝符号链接），主题、字号、自动编译、折叠面板与模型配置在重启桌面应用后完整保留；补充中文桌面壳本地化文案。
  - 将 `window.confirm_close` 与编辑区脏状态同步，关闭含未保存改动的窗口前弹出确认；在收到 `SIGTERM` 时主动清理确认门禁与 POSIX wakeup pipe，维持有界优雅退出（退出码 `0`）。
  - 为 macOS 原生菜单栏注入「编辑 → 撤销 (`⌘Z`) / 重做 (`⇧⌘Z`)」，自动区分 Monaco 编辑器、普通表单输入框与模态对话框焦点状态，并缓存 PyObjC 辅助类避免重复注册崩溃。
- **离线 TeX 预热缓存补全与全模板/示例零缺失离线编译（#82 / PR #86）**：
  - 扩展 `scripts/prepare-local-tex.py` 预热样例，完整覆盖 `ctexart`、`ctexbeamer`、`article`（`10pt`/`11pt`/`12pt`）、`amsthm`、`geometry`、`amsmath`、`amssymb`、`graphicx`、`booktabs` 以及 `11pt`/`12pt` 数学角标字体（`cmmi8`/`cmsy8`/`cmmi6` 等）；既有用户升级后启动时通过增量缓存合并自动补齐新增离线资源。
  - 将 `samples/docs/exam-01.tex` 与 `samples/docs/report-01.tex` 切换为内置 Fandol 字体的 `\documentclass[UTF8,fontset=fandol]{ctexart}`，消除缺失系统字体导致的离线编译失败。
  - 清理 5 套内置新建文档模板中的误报触发点（保持 `S13` 等合同样本不变），确保全部内置模板打开即零误报且完全离线可编译。
- **Studio 诊断分类、候选编译反馈、本地模型下拉同步与看板 Diff 修正（#83 / PR #88）**：
  - 底部问题列表为 `cleanup` 诊断提供专属「文档清洗」标签与样式，不再误归类为「表格合计」。
  - Agent 候选结果与质检报告统一采用 `compile_ok ?? ok` 判定编译状态，`NOT_CHECKED` 采用中性色显示；缺少 `pdftoppm` 时仍开放 PDF 导出，候选编译失败时明确展示 TeX 报错摘要（兼容 Windows 路径）。
  - 打开「设置 → 本地模型」时将模型下拉框与当前运行中的受管配置同步（如 `35b`），且不覆盖用户后续手动切换。
  - 修复 `webui/index.html` 看板「修复后 · repaired.tex」列 `diffSpans` 传参反序导致的原公式重复显示问题。
- **跨平台运行时、Windows 诊断路径、UTF-8 编码与受损配置恢复（#84 / PR #87）**：
  - `_source_compile_error` 兼容 Windows 盘符路径（`C:\...\main.tex`）、相对路径（`.\main.tex`）与大小写/斜杠归一化；`_studio_compile` 合并非空 `stderr` 与 `stdout` 避免丢弃关键错误；`studio_pdf` 改用 `removesuffix(".tex")` 精准拼接输出名。
  - `webui/app.py` 与 `harness/docforensics/pipeline.py` 的确定性检查子进程统一强制 `encoding="utf-8", errors="replace"` 与 Windows `CREATE_NO_WINDOW`；`desktop/windows_entry.py` 同步配置 `sys.stdin` UTF-8 编码。
  - `scripts/run-local-studio.py` 检测到损坏的 `local-runtime.json` 时给出明确告警并回退默认配置，避免启动即崩溃且支持 CLI 覆盖恢复；`LocalProvider.__init__` 正确初始化 `self.skill_root`。

## 验证与验收记录

- **双平台自动化回归**：全仓 6 套 Python 测试套件共 **801 项**单测（`python -W error` 零警告字节码编译）、**4 套** Node.js 回归与 **27 / 27** 公式检查器契约案例在 `ubuntu-latest` 与 `windows-latest` 双系统矩阵全绿通过。
- **隔离打包全离线冒烟证据**：
  - **macOS（`macos-15`）**：在剥离仓库与 Homebrew 的隔离 `HOME` 下，以 `--untrusted --only-cached` 严格离线编译全部 5 套内置模板（空白文章、课堂讲义、试卷、Beamer、英文论文）以及 `welcome.tex`、`clean-control.tex`、`math-clean.tex`、`math-semantics.tex`、`report-01.tex`，并验证捆绑 `pdfinfo`、`pdftoppm` 中文 CJK 渲染、`llama-server`、Developer ID 签名、Apple 公证装订、`spctl` Gatekeeper 与 `SIGTERM` 有界退出。
  - **Windows（`windows-latest`）**：在清空构建缓存、仅保留 `System32` 最小 `PATH` 的隔离环境下，同样完成全部 5 套内置模板与 5 份代表性示例的严格离线 `tectonic.exe` 编译、冻结检查器（`verify.py`）、`pdftoppm.exe` 中文与 `\phantom` 空白像素差异比对及 `llama-server.exe`（build `12631`）启动校验。

## 使用与摘要核验

安装包不包含模型权重（1B `Q4_K_M` 含视觉投影约 1.8 GB，35B-A3B `Q4_K_M` 约 22.3 GB；参见 [README 配置说明](../../README.md#配置)）。确定性语法修复、离线编译与编辑功能无需模型服务即可使用。所有 OCR 转写与修复候选均须对照原件人工审阅后保存。

下载发行包后请核对随附的 SHA-256 摘要：

- **macOS**：
  ```bash
  shasum -a 256 -c checksum.txt
  ```
- **Windows（PowerShell）**：
  ```powershell
  Get-FileHash .\TeXada-Studio-Windows-x64.zip -Algorithm SHA256
  Get-Content .\checksum-windows.txt
  ```
