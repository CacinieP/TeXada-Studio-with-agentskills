# TeXada Studio v0.1.4

端到端 AgentSkills 协同修复与工作台交互打磨正式发行版，同时提供 **macOS 15+ / Apple Silicon 自包含公证安装包**（`CFBundleShortVersionString` `0.1.4`，build `9`）、**Windows 10/11 x64 自包含便携桌面包**（`TeXada-Studio-Windows-x64.zip`，可执行版本 `0.1.4.0`）与固定提交跨平台源码包。

## 修复与改进

- **文档清洗边界修正与混合零宽噪声保底清理（#96）**：
  - `harness/docforensics/tex_cleanup.py` 仅在存在尾部遮罩型数学诊断（`unclosed_math` / `mismatched_environment`）时抑制跨行花括号判定，修复正文中存在孤立 `\]`（`unexpected_math_close`）时导言区或前文未闭合命令（如 `\author{TeXada Studio`）被漏检且无法修复的问题。
  - 新增 `strip_zero_width_candidate` 与 `assess_zero_width_cleanup` 来源守卫：当文档同时存在零宽格式噪声（`\ufeff` / `\u200b` / `\u200c` / `\u200d`）与未闭合命令/环境时，调用模型前先剥离非保护区零宽字符（消除模型原样回显不可见字符导致的 `unauthorized_cleanup_change` 误拒），并在模型不可用或候选被拒时保底保留确定性零宽清理；`repair_context.checker.reason` 同步传入全部清洗缺口的行号与类型。
- **MiniCPM 1B 自动选 Skill 约束与结构闭合可靠性提升（#96）**：
  - 针对 `minicpm-v4.7-1b-q4_k_m`（含 Studio 内置管理进程与外部复用的同别名 `llama-server`），在 `webui/local_runtime.py` 中为 `select_skill` 增加 `select_skill_choice` 编号 JSON Schema 约束（消除将表格节点误路由到 `doc-formula-verify` 的 `skill_not_applicable` 失败），为 `repair_table` 与 `repair_cleanup` 挂载严格 `json_schema` 输出契约。
  - 对多缺口或含未闭合正文环境（如 `itemize` / `center`）的文档提供有界结构闭合选项（`studio_cleanup_choices`，保证同位置嵌套环境遵循「内先外后」闭合顺序），解决 1B 全文重写遗漏末尾 `\end{document}` 或附带多余字段的问题，同时保持宿主 `assess_cleanup_candidate` 全量零信任回判不变。
- **编译器日志路径脱敏与桌面升级静态资源协商缓存（#96 / #97）**：
  - `webui/app.py:_studio_compile` 在提取 `main.tex` 行号诊断后自动剥离内部 `STUDIO_STATE/builds/...` 宿主机绝对路径前缀，避免本机目录结构进入 `#pvLog`、`#joblog` 或导出的 `.audit.md` 质检报告。
  - `/static/editor/*` 与 `/static/brand/*` 增加 `Cache-Control: no-cache` 响应头，确保开启持久化 WebView 存储的桌面应用在版本升级后立即加载新版样式与脚本。
- **候选过期清理、历史记录只读恢复、撤销/重做同步与命令面板键盘直达（#97）**：
  - 原文编辑导致待审阅候选过期时立即销毁陈旧 `diffEditor` 并收起「修复对比」标签页；点击源码已变更或已有决定的历史任务时，同步更新只读编译摘要与目标文档名，支持直接导出对应历史任务的 `.audit.md` 报告且不强行展开已收起的侧栏。
  - 切换或新建文档时立即归零 `#probCount`、滚动条（`scrollTop = 0`）与光标（`1:1`），关闭短 LaTeX 文档中遮挡正文的 Monaco `stickyScroll`；采用候选后自动聚焦编辑器，补齐 `⌘/Ctrl+Z` 与 `⌘/Ctrl+⇧+Z`（`⌘/Ctrl+Y`）撤销重做快捷键并实时重跑 `analyze()` 同步问题计数与审阅提示。
  - 在未修改地址与模型名称时点击「保存设置」保留已探测的 `已连接` / `未连接` 状态；拦截命令面板（`⌘⇧P`）按 `Enter` 执行命令后物理按键抬起触发的合成点击，并为「转到章节」「从模板新建」弹窗补齐上下方向键导航；修复「最近运行」刷新图标按钮被撑满整行的问题。

## 使用与摘要核验

安装包不包含模型权重（1B `Q4_K_M` 含视觉投影约 1.8 GB，35B-A3B `Q4_K_M` 约 22.3 GB；参见 [README 配置说明](../../README.md#配置)）。确定性语法修复、离线编译与编辑功能无需模型服务即可使用。所有 OCR 转写与修复候选均须对照原件人工审阅后保存。

下载发行包后请核对随附的 SHA-256 摘要：

- **macOS**：
  ```bash
  shasum -a 256 -c checksum.txt
  ```
- **Windows（PowerShell）**：
  ```powershell
  Get-FileHash .\TeXada-Studio-Windows-x64.zip -Algorithm SHA256
  Get-Content .\checksum-windows.txt
  ```
