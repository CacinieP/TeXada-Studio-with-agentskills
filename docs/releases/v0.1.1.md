# TeXada Studio v0.1.1

双平台正式发行版，同时提供 **macOS 15+ / Apple Silicon 自包含公证安装包**（`CFBundleShortVersionString` `0.1.1`，build `6`）、**Windows 10/11 x64 自包含便携桌面包**（`TeXada-Studio-Windows-x64.zip`，可执行版本 `0.1.1.0`）与固定提交跨平台源码包。

## 新增与修复

- **保真型 AgentSkills 三技能修复执行闭环（#76 / #78）**：
  - **`doc-formula-verify`（`1.4.0`）**：在 `assess_candidate` 中开放带赤字门禁的保序结构定界插入（`structural_delimiter_insertion`），仅当原公式存在未闭合 `{`/`}` 或未配对 `\left`/`\right` 赤字时，允许模型按源码字符保序补齐缺失定界符并经 `anchor_guard` + `verify.py` 双重校验放行；严密拦截空上下标填词、数字/小数字面量内部拆裂、算子后越位插 `{` 或 `\left(` 改变结合优先级、并置原子间猜右边界（`S09`）与错配左右定界符。
  - **`doc-table-audit`**：Studio 在确定性重算可修复合计错数后，对缺列或空单元格合计行（如 `合计 \\`、`合计 & \\`）按需加载 `doc-table-audit` Skill 调用 `provider.repair_table`，经逐行数据行防篡改校验、保留 `%` 注释与二次 `audit_table.py` 复核后生成待审候选。
  - **`latex-cleanup`（`0.2.3`）**：纳入第 3 白名单技能与受限规划器（`check-cleanup` → `cleanup-document`），无清洗问题的文档不生成节点、既有预算零膨胀；支持确定性清除正文内零宽字符噪声（保留数学、原样文本、注释与文件首 BOM）及非数学单行命令同行闭合、未闭合环境收尾（基于 `mask_opaque` 隔离数学与表格区间），并为长文档动态保底 `max_tokens`。
- **Windows x64 全栈运行时、双系统回归矩阵与自包含便携包（#77 / #79）**：
  - **一键工具自举与受管模型适配**：`tool_fetch.py` 新增 Windows x64 固定版本 Tectonic `0.17.0` MSVC 与 Poppler Windows `v26.09.0-0`（保留 `Library/bin` 与 `share/poppler` CJK 字形映射目录层级，均强制 SHA-256 校验与占用重命名恢复）一键安装；`managed_models.py`、`local_runtime.py` 与 `app.py` 适配 `llama-server.exe`、`%LOCALAPPDATA%\TeXada Studio` 数据目录及 `CREATE_NO_WINDOW` 无黑框子进程调用；新增 `scripts/start-local-studio.bat` 启动器。
  - **Win32 进程与 NTFS 存储安全**：通过 Win32 `OpenProcess(SYNCHRONIZE)` + `WaitForSingleObject` 探测进程存活与父进程孤儿态，消除 Windows 上 `os.kill(pid, 0)` 误杀语义与 `os.getppid()` 固化盲区；Windows 桌面看门狗采用 Winsock `socketpair` 消除 `select.select` `WinError 10038`；`document_store.py` 拦截全部 NTFS 保留设备名（`CON`、`PRN`、`AUX`、`NUL`、`COM1..9`、`LPT1..9` 及带扩展名变体）与 `st_ino == 0` 假阳性冲突。
  - **双系统 CI 与 Windows 自包含便携桌面包**：`.github/workflows/regression.yml` 升级为 `ubuntu-latest` + `windows-latest` 双系统全量回归矩阵；新增 `desktop/build_windows_bundle.py`、`desktop/windows_entry.py` 与 `.github/workflows/windows-bundle.yml`，基于 PyInstaller `--onedir --windowed` + Edge WebView2 产出内置 Python、Tectonic、预热 `tex-cache`、Poppler+CJK、`llama-server.exe`（`b12631` CPU x64）与多尺寸 Vista+ `AppIcon.ico` 的自包含便携包，冻结入口同时承接包内确定性检查器调用。

## 验证与验收记录

- **双平台自动化回归**：全仓 6 套 Python 测试套件共 **787 项**单测（`python -W error` 零警告字节码编译）、**4 套** Node.js 回归与 **27 / 27** 公式检查器契约案例在 `ubuntu-latest` 与 `windows-latest` 双系统矩阵全绿通过。

  - **macOS（`macos-15`）**：在剥离仓库与 Homebrew 的隔离 `HOME` 下验证捆绑 `tectonic`、`pdfinfo`、`pdftoppm` 中文 CJK 渲染、`llama-server`、Developer ID 签名、Apple 公证装订、`spctl` Gatekeeper 与 `SIGTERM` 有界退出。
  - **Windows（`windows-latest`）**：在清空构建缓存、仅保留 `System32` 最小 `PATH` 的隔离环境下验证 `TeXada Studio.exe` 冻结检查器（`verify.py`）、`tectonic.exe` 离线中文编译、`pdftoppm.exe` 中文与 `\phantom` 空白像素差异比对及 `llama-server.exe`（build `12631`）启动校验。

## 使用与摘要核验

安装包不包含模型权重（1B `Q4_K_M` 含视觉投影约 1.8 GB，35B-A3B `Q4_K_M` 约 22.3 GB；参见 [README 配置说明](../../README.md#配置)）。确定性语法修复、离线编译与编辑功能无需模型服务即可使用。所有 OCR 转写与修复候选均须对照原件人工审阅后保存。

下载发行包后请核对随附的 SHA-256 摘要：

- **macOS**：
  ```bash
  shasum -a 256 -c checksum.txt
  ```
- **Windows（PowerShell）**：
  ```powershell
  Get-FileHash .\TeXada-Studio-Windows-x64.zip -Algorithm SHA256
  Get-Content .\checksum-windows.txt
  ```
