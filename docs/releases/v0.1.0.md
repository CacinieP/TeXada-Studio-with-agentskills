# TeXada Studio v0.1.0

正式发行版，macOS 15+ / Apple Silicon 自包含公证安装包（`CFBundleShortVersionString` `0.1.0`，build `5`）及固定提交跨平台源码包。

## 新增与修复

- **Studio 管理的本地模型（MiniCPM-V 4.7 1B / 35B-A3B）**：在「本地模型」面板支持按需下载经 SHA-256 校验与断点续传的 OpenBMB `Q4_K_M` 权重及对应 `F16` 视觉投影，并在本机拉起独立脱敏 `llama-server` 同时供修复候选与图片/PDF 转写使用；停止或退出后自动恢复此前保存的本机端点。macOS 自包含安装包内置 `llama-server` 运行时与许可证声明，不预置模型权重。
- **自包含包中文 PDF 渲染（#61 / #62）**：捆绑基于 `poppler-cpp` 的页面渲染器与经校验的 `poppler-data` 字符映射表，在无 Homebrew、仅系统 `PATH` 的隔离环境中原生渲染中文标题、正文与数学公式，并在打包流水线加入中文与空白对照像素冒烟检查。
- **审阅反馈、撤销重做与诊断跳转（#54 / #55 / #57）**：采纳 Agent 修复候选记入编辑器单步撤销历史，工具栏、命令面板与快捷键支持撤销和重做并自动使旧 PDF 预览失效；Agent 0 改动任务保持编辑视图并区分待人工核对项与编译诊断；Tectonic 编译报错与检查问题项支持按键跳转到源码行。
- **公式、矩阵、表格与 TeX 扫描保真加固（#63 / #64 / #71 / #73）**：补齐 `\left`/`\right`/`\middle` 配对与重上下标词法检查，校验矩阵与 1/2 列 `cases` 的外围骨架及单元格语法，支持 `\text{...}` 内嵌 `$` 与 `0^+`/`0^-` 单侧极限上标，修复多行编辑后确定性兜底的公式节点对齐与行号更新；表格合计仅精确匹配 `合计`/`总计`/`total` 标签并隔离 `%` 注释干扰；同步更新 `doc-table-audit` 等 AgentSkills 契约。
- **桌面端、存储与工作台安全卫生（#50 / #65 / #66 / #74）**：支持 macOS Cocoa 事件循环及启动期 `SIGTERM` 有界退出并规避窗口未完成 `shown` 时的主线程死锁；桌面启动预检回环端口空闲并以 `0o600` 原子写入 `session.json` 与 `model-server.log`；修复 Monaco 多行矩阵/环境片段反斜杠转义及 macOS APFS 大小写不敏感重命名与 NFD 归一化。

- **端到端与隔离环境验证**：E2E-1..4（真实 Tectonic 编译、真实本地模型修复落稿、OCR 行转布局、跨进程状态持久化）留证见 [E2E 发行验收记录](../evaluation-results/e2e-release-01/SUMMARY.md)，E2E-5 `.app` 启动与 `SIGTERM` 有界退出场景及原生 Cocoa 集成验证见 `scripts/e2e_release_check.py` 与 `desktop/test_desktop.py`；GitHub Actions `macos-15` 在无仓库、无 Homebrew、无网络的隔离 `HOME` 下验证捆绑 `tectonic`、`pdfinfo`、`pdftoppm`（含中文 CJK 像素校验）、`llama-server`、Developer ID 签名、Apple 公证装订与 `spctl` Gatekeeper 检查。

## 使用与边界

安装包不包含模型权重：1B `Q4_K_M`（含视觉投影）约需 1.8 GB 磁盘空间，默认推荐的 35B-A3B `Q4_K_M` 约需 22.3 GB 磁盘空间及充足统一内存（参见 [README 配置说明](../../README.md#配置)）。确定性语法修复、离线编译与编辑功能无需模型服务即可使用。

语法检查通过与编译通过不等于数学命题成立或 OCR 转写忠实，所有识别结果与修复候选均须对照原件人工审阅后保存。macOS 原生系统菜单栏 Edit → Undo/Redo 项仍由 #54 跟踪，多来源真实图像区域检测与独立人工质量基准仍由 #24 跟踪。

下载安装包后请使用随附的 `checksum.txt` 核对 SHA-256 摘要：

```bash
shasum -a 256 -c checksum.txt
```
