# TeXada Studio v0.1.3

双平台稳定性与端到端可用性正式发行版（含未单独发版的 `0.1.2` 全部改动），同时提供 **macOS 15+ / Apple Silicon 自包含公证安装包**（`CFBundleShortVersionString` `0.1.3`，build `8`）、**Windows 10/11 x64 自包含便携桌面包**（`TeXada-Studio-Windows-x64.zip`，可执行版本 `0.1.3.0`）与固定提交跨平台源码包。

## 修复与改进

- **macOS 自包含 `llama-server` 计算后端修复与越界依赖门禁（#90 / PR #92）**：
  - `desktop/build_bundle.py --with-llama-server` 自动检测本机 Homebrew `ggml` 动态后端插件构建（依赖 `/opt/homebrew/.../libexec/libggml-*.so`、在 Hardened Runtime 或干净 Mac 上启动即崩溃），并切换为 SHA-256 锁定的官方 `llama.cpp` `b12631` macOS arm64 归档（`libggml-metal` / `libggml-blas` / `libggml-cpu` 直连捆绑至 `tools-lib`）。
  - 打包与 CI（含 Developer ID + Hardened Runtime 签名后）增加 `DYLD_PRINT_LIBRARIES=1 llama-server --list-devices` 隔离校验，同时拒绝无计算后端 `(none)` 与任何包外动态库加载。
  - `webui/managed_models.py` 记录启动前 `model-server.log` 字节偏移，仅从当次启动新写入日志中提取报错原因，避免误报历史残留崩溃。
- **模型缺失/断连降级、双模式早停与前端可见提示（#91 / #93 / PR #92 / PR #94）**：
  - `/api/studio/fix` 在执行前探测配置的回环模型；模型缺失或服务未启动时立即记录「模型服务不可用：…」并降级仅执行确定性修复，不再空转消耗预算。
  - 任务中途出现传输级失败（`provider_error` / `http_error` / `network_error` / `timeout`）时，无论是受限规划器模式还是默认非规划修复链路（公式、表格、清洗），均在连续 2 次失败后早停（规划器标记 `provider_unavailable` 并发出 `PLANNER_ABORTED`；默认链路发出 `PROVIDER_ABORTED` 并继续完成其余确定性修复），同时记录脱敏后的 HTTP 状态与 provider 错误信息（剥离 URL、凭据与长 token）。
  - `_studio_job` 在降级或早停时输出结构化 `model_warning`，Studio 前端在 Agent 审阅提示区（`#reviewHint`）与提示条中直观展示该原因，无需手动展开默认折叠的日志抽屉。
- **桌面端原生文件导出、偏好持久化、未保存关闭提醒与 macOS 原生撤销/重做（#54 / #81 / PR #85）**：
  - 修复 macOS `WKWebView` 与 Windows `WebView2` 点击导出 `.tex` / `.pdf` / 质检报告无响应问题：开启 `ALLOW_DOWNLOADS` 并提供最小桥接 `save_file`（系统原生保存框 + 原子覆盖写盘）；浏览器模式延长 Blob Object URL 回收窗口。
  - 启用持久化 WebView 存储（`state_dir/webview-storage`，权限 `0o700` 并拒绝符号链接）与中文本地化文案；将 `window.confirm_close` 与编辑区脏状态同步，同时在 `SIGTERM` 时主动解除确认门禁并清理 POSIX wakeup pipe，维持有界优雅退出（退出码 `0`）。
  - 为 macOS 原生菜单栏注入「编辑 → 撤销 (`⌘Z`) / 重做 (`⇧⌘Z`)」，自动区分 Monaco 编辑器、普通表单输入框与模态对话框，并缓存 PyObjC 辅助类。
- **离线 TeX 全模板 + 30+ 常用宏包预热与完整缓存升级合并（#82 / #92 / #93 / PR #86 / PR #92 / PR #94）**：
  - `scripts/prepare-local-tex.py` 扩展预热样例，完整覆盖 `ctexart`、`ctexbeamer`、`article`（`10pt`/`11pt`/`12pt`）、`11pt`/`12pt` 数学角标字体（`cmmi8`/`cmsy8`/`cmmi6`）以及 `geometry`、`hyperref`、`xcolor`、`enumitem`、`mathtools`、`booktabs`、`longtable`、`array`、`multirow`、`tabularx`、`makecell`、`caption`/`subcaption`、`cleveref`、`float`、`setspace`、`fancyhdr`、`titlesec`、`parskip`、`ragged2e`、`listings`、`ulem`、`microtype`、`etoolbox`、`csquotes`、`textcomp`、`lmodern`、`bm`、`mathrsfs`、`cancel`、`tikz` 等 30+ 常用宏包，离线缺包时直接列出缺失的 `.sty`。
  - 将 `samples/docs/exam-01.tex` 与 `samples/docs/report-01.tex` 切换为内置 Fandol 字体的 `ctexart` 并清理 5 套内置新建文档模板误报；`desktop/app.py:seed_tex_cache()` 在目标缓存目录已存在时除补齐 `bundles/data/<64hex>/*` 外同步原子补齐缺失的 `.index`、`.prefetch`、`bundles/hashes/*` 与 `formats/*.fmt`。
- **Studio 诊断分类、候选编译反馈、跨平台路径与 UTF-8 编码加固（#83 / #84 / #93 / PR #87 / PR #88 / PR #94）**：
  - 底部问题列表为 `cleanup` 提供专属「文档清洗」标签；候选结果与质检报告统一采用 `compile_ok ?? ok`（`NOT_CHECKED` 中性色、缺 `pdftoppm` 时仍支持 PDF 导出、编译失败明确展示诊断）；打开设置同步受管模型下拉框；修正 `webui/index.html` 看板修复列 Diff 方向。
  - 支持 Windows 绝对/相对路径编译行定位、合并非空 `stderr`/`stdout`、安全去除 `.tex` 后缀；统一为公式/表格/Harness 检查器、`pdfinfo`、`llama-server --version`、`_compile_latex`、`_run_pipeline` 与 `windows_entry.py` 强制 `UTF-8` 解码与 Windows 无黑框参数；修复损坏 `local-runtime.json` 导致启动器崩溃，并补全 `LocalProvider.skill_root`。

## 使用与摘要核验

安装包不包含模型权重（1B `Q4_K_M` 含视觉投影约 1.8 GB，35B-A3B `Q4_K_M` 约 22.3 GB；参见 [README 配置说明](../../README.md#配置)）。确定性语法修复、离线编译与编辑功能无需模型服务即可使用。所有 OCR 转写与修复候选均须对照原件人工审阅后保存。

下载发行包后请核对随附的 SHA-256 摘要：

- **macOS**：
  ```bash
  shasum -a 256 -c checksum.txt
  ```
- **Windows（PowerShell）**：
  ```powershell
  Get-FileHash .\TeXada-Studio-Windows-x64.zip -Algorithm SHA256
  Get-Content .\checksum-windows.txt
  ```
