# TeXada Studio v0.2.0-beta.2 发布说明草稿

预发布。tag `v0.2.0-beta.2` 指向包含本说明的提交。上一版远端 tag 是 `v0.2.0-beta.1`（`b407bbc`）。本草稿随源码包的 `manifest.json` 里的 `commit` 字段对应同一次打包。GitHub Release 随该 tag 发布，桌面安装包由 tag 触发的打包流水线产出。

## 这一版相对 beta.1

- 公式候选增加来源范围、锚点漂移和节点 revision 绑定。
- 修复线模型按 `REPAIR_MODEL`、`VLM_MODEL`、内置默认的顺序选择。
- 表格候选实现 `repair_table` 网格契约，并由 `assess_table_candidate` 限制为合计行上的授权改动。
- 自包含应用的 Finder 图标改为品牌 `AppIcon`。写入图标后重新做 ad-hoc 签名，避免 py2app 的签名因 `Info.plist` 改动失效。

## 本机验证

- 环境：macOS arm64，Homebrew Python 3.13.16 用于 py2app；日常开发虚拟环境仍是 uv CPython 3.13.13。
- 与 Studio regression 相同的本地检查通过：harness 162、webui 178、scripts 82、desktop 15、latex-cleanup 77，以及四组 JavaScript 行为测试、`compileall` 和内联脚本语法检查。
- 应用包由当前提交的 `desktop/build_bundle.py` 重新生成：`dist/TeXada Studio.app`，`CFBundleShortVersionString` 为 `0.2.0`，`CFBundleIconFile` 为 `AppIcon`。包内 Python 是 Homebrew CPython 3.13.16，许可说明与此一致。打进应用的 TeX 缓存清单在构建时按实际文件生成，与 `desktop/tex-cache-manifest.sha256` 的 335 行一致。`codesign --verify --deep --strict` 通过。剥离 `PATH`/`HOME` 后，包内 Tectonic 0.17.0 只用捆绑缓存编译出 `smoke.pdf`。
- 包内 harness、webui、skills、desktop 中与仓库对应的 177 个源码文件，SHA256 与打包时的工作区一致。
- Gitleaks 8.30.1 扫描本说明之前的 `main` 历史，没有未处理泄漏。自 `v0.2.0-beta.1` 新增的 4 张品牌图没有文本或 EXIF 元数据，画面只有品牌图形；`strings` 检查也未发现本机路径、邮箱或凭据。
- 仓库已开启 Private vulnerability reporting。没有发送测试报告。
- 源码包由 `bash scripts/package.sh` 从该提交生成，并用附带的 `SHA256SUMS` 核对。
- 动态演示清单中的 4 个交付文件与 `docs/media/dynamic-demo-manifest.json` 的字节数和 SHA256 一致：无配音实录、配音实录、字幕和旁白稿。这些文件不进入源码包。
