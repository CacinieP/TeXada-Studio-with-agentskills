## 这一版解决什么

在浏览器里检查部分行内公式语法和简单表格合计；查看规则或本地模型提出的候选差异，人工采用，再导出 tex、PDF 与质检记录。合计错误可能不影响编译，公式语法通过也不等于语义正确，因此保留检查依据和人工确认。

## 已实现

- Monaco 本地静态资源；源码编辑、上传/导出单文件、第一页 PDF 预览。
- 简单表格合计重算候选；公式文本候选、语法回判和编译状态。
- 采用前的候选 diff，包含修改与内容摘要的质检报告。
- 独立 CLI 的已有布局树处理、fixture 测试、事件记录与终态续跑。
- 中文/英文入门、求助与安全说明、13份Studio样本和本地检查命令。
- 新增8份数学讲义的检查契约，以及8份原稿和4份作者参考修订的独立编译证据；真实模型修复另有视频与逐候选记录。

## 安装与尝试

从 README 的无需 GPU fixture 开始，再按 Studio 依赖表准备本地模型、Tectonic、Poppler 和字体。不要假设实测节点的模型标签在其他机器上存在。

## 已知限制

实验性单进程程序；执行中的任务依赖内存，完成结果可按已知任务ID读取，中断任务需新建；不接收不可信 TeX；无多用户隔离、OCR、多文件项目或多页预览。CLI 的真实模型路径尚未实现表格修复。首次 TeX 编译可能联网。合成 fixture 不代表真实模型准确率。

没有自动 CI 工作流，也未建立跨平台和多模型性能基准。发布时只列出实际执行的检查，不沿用未复核的绿色状态。

## 附件与反馈

建议附源码 ZIP、SHA256SUMS、制作完成的短片或完整演示播放链接。不要附私人 Git bundle、节点资料、用户文档、私人媒体素材或模型权重。

一般问题走 SUPPORT.md；安全问题走 SECURITY.md。源码许可为 AGPL-3.0-only，第三方资源保留原许可。贡献任务见路线图。
