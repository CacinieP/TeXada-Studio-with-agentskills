# TeXada Studio v0.1.0-alpha.1 发布说明草稿

首个预发布版本的候选说明；tag和GitHub Release待创建。源码和[B站演示](https://www.bilibili.com/video/BV16Kan6rEGv/)已提供公开入口。

## 这一版提供什么

在浏览器中检查行内公式语法和简单表格合计，审阅候选diff，手动采用后导出TeX、PDF和质检报告。

- 本地Monaco编辑器，单文件上传和导出，PDF第一页预览。
- 规则重算表格合计；本地模型提出公式候选，由检查器回判并展示编译结果。
- CLI处理已有布局树，记录候选和事件，按输入与执行上下文续跑。
- 中英文入门、13份Studio样本、27个检查案例及12项样本编译复现命令。

## 使用范围

本版面向可信用户和文档，采用单进程、共享token。公式提取限于同一行的`$...$`，数学含义需要人工核对。自动OCR、多文件项目、多页预览及多用户隔离待实现；CLI真实模型路径目前只修复公式。Studio中断任务需重新发起，完成结果可按任务ID读取。
