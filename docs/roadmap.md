## 适合第一次贡献的任务

| 任务 | 做什么 | 提交时如何验收 |
| --- | --- | --- |
| 补一个表格边界 | 在[案例集](../samples/evaluation/README.md)添加原创最小输入、稳定ID和预期原因 | 运行 `python scripts/evaluate_cases.py --outdir state/evaluation-new`，附新报告与契约说明 |
| 验证一个安装环境 | 按中英文README建立独立环境，运行fixture两次 | 附OS、架构、Python版本、首轮计数、续跑结果和必要文档修正 |
| 修一处文档或错误说明 | 找到具体命令、输出或中英文差异 | 给出修改前的复现和修改后的实际输出，检查相关链接 |
| 检查键盘与面板操作 | 逐步检查Tab焦点、按钮、折叠和恢复 | 记录步骤与实际行为；修改UI后运行 `node webui/test_studio.cjs`，补浏览器操作核对 |

开始前说明要改的路径和完成标准。一个PR围绕一个可复现问题，样本使用原创或许可明确的材料，截图移除访问凭据。
