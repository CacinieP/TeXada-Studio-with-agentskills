## 适合第一次贡献的任务草案

### 1. 补充一个表格边界样本

用原创、可再分发的最小表格说明现有误检/漏检，写清期望行为与限制。通过现有审计入口复现，测试应覆盖用户可观察行为；不把未支持语法强行标作成功。先提 Issue 确认预期，再提交小 PR。

### 2. 验证一个新的安装环境

按 README 在独立环境运行 fixture，记录 OS、架构、Python 版本、安装失败点、首轮计数和续跑结果。提交脱敏记录及必要文档修改，不宣称覆盖未测平台。没有 GPU 也能参与。

### 3. 改善英文文档与错误说明

核对 `README.en.md` 与中文的能力矩阵、命令、限制是否一致，附具体差异和修正文案。中文姓名保持原写法，不替成员编造英文姓名或 ORCID。

### 4. 验证键盘操作与折叠控件

记录 Tab 焦点、按钮名称、键盘可触达性与折叠后恢复的实际行为。截图不带凭据。先提供复现，再在 `webui/studio.html` 做小范围修复；检查 Monaco 编辑与面板操作不互相遮挡。

认领时说明计划修改的路径与验收办法；不要同时重写多个模块。参与流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)，目前没有自动分配、奖励或合并时限承诺。
