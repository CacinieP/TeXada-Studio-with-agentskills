# 本地版范围与后续工作

本轮目标是 TeXWizard 风格的单用户本地 TeXada Studio：输入资料、编辑与检查、审阅候选、保存和导出形成完整流程。实现状态与实机验收状态分别记录，最终结果以[本地版验收报告](local-studio-acceptance.md)为准。

## 本机验收与剩余验证

本次已完成本机 1B Q4 图片/PDF 转写、候选编译、一次公式修复、Chrome 主要交互及多页 PDF 交付。当前自动化记录为 283 项 Python 回归、前端 VM 检查和 27/27 确定性检查器案例。确切版本、输入和步骤见[验收报告](local-studio-acceptance.md)。

这些是本机 smoke，不能替代以下独立工作：

- 从另一台机器的干净源码包安装，检查首次准备、启动和续跑。
- 扩展真实授权图片、手写与论文文档，逐项对照原件并完成独立人工语义复核。
- 对不同字体、宏包、文档类和更多 TeX 环境扩展离线编译覆盖。
- 继续记录缺模型、缺资源、中断、取消、过期候选和版本冲突，保留失败样例。
- 按任务来源、模型和环境分别报告；不把本机流程成功算成数学或 OCR 准确率。

## 当前范围以外

多文件 TeX 工程、项目依赖管理、多用户服务、多人协作及公网托管不属于这次单用户本地版交付。若后续启动，应分别设计入口/依赖、编译隔离、用户与数据边界，并单独验收。

CLI 的已有 `layout.json` 工作流继续保留，不能据 Studio 增加 OCR 就推断 CLI 已自动具备同样的输入链路。旧云 API 与实验规划入口见[本地指南](local-studio.md#旧云-api-入口与实验功能)。

新增样本应保留原创或许可来源；每项变更附可重现输入、实际结果和限制。参与方式见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
